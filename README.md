# I use oxwm, btw.
## https://github.com/tonybanters/oxwm
My dotfiles are very simple and they don't really have anything "new" in them. They aim to be as minimalistic as possible.

# Dependencies
Note: These are NOT required. You can still use my dotfiles, with whatever terminal/compositor/wallpaper manager you want. Just keep in mind that you have to edit config.lua then!  
  
Flameshot (Screenshot App)  
Alacritty (Terminal)  
Picom (Compositor)  
xwallpaper (Wallpapers)  


# Keybinds
Super + D -> DMenu  
Super + Q -> Kill focused window  
Super + Print -> Screenshot (Flameshot)  
Super + 1-9 -> Switch workspaces  
Super + Enter -> Terminal
